# Architecture Decision Records

Decisions made while building goache, in the order they happened. Each record
uses the same template: Context, Decision, Consequences, and (where
applicable) Alternatives Tried — including approaches that were implemented,
measured, and reverted. Those are kept as records, not deleted, so they're
not re-attempted blind.
